Streaming

Results arrive in pieces

This is the actual event sequence the reporter agent sends for SendStreamingMessage. The first event is the task, then status updates and artifact chunks. A client rebuilds the report by appending each chunk.

Bindings

One protocol, two ways to say it

The same SendMessage, spoken as JSON-RPC and as plain HTTP+JSON. The message payload, highlighted, does not change. The testbed serves both for every agent, and the client picks one from the Agent Card.

JSON-RPC 2.0

POST /reporter/rpc
{ "jsonrpc": "2.0", "id": 1,
  "method": "SendMessage",
  "params": {
    "message": {
      "messageId": "m1",
      "role": "ROLE_USER",
      "parts": [{ "text": "fusion power" }]
    }
  } }

HTTP+JSON

POST /reporter/rest/message:send
